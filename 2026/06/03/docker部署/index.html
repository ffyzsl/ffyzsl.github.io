发表于 2026-06-03

1. Docker 是什么？

想象你要去朋友家做饭，但朋友家的厨房和你家的完全不一样——调料放哪、锅用什么牌子、火力大小全都不一样。结果你手忙脚乱，菜做砸了。

Docker 的解决方案：把你家厨房整个打包成一个箱子，提着箱子去任何地方，打开就能做饭。这个箱子就是 容器（Container）。

核心三件套

概念 一句话 类比
镜像（Image） 容器的”模板”，包含运行环境和代码 一份菜谱
容器（Container） 镜像的运行实例，隔离运行 按菜谱做出来的菜
仓库（Registry） 存储和分发镜像的地方 菜谱分享平台（Docker Hub）

3.4 Docker run 常用参数速查

参数 说明 示例
-d 后台运行 docker run -d nginx
--name 指定容器名 --name myapp
-p 端口映射 -p 8080:80（宿主机:容器）
-v 挂载数据卷 -v /host/path:/container/path
-e 设置环境变量 -e DATABASE_URL=postgres://...
--env-file 从文件读取环境变量 --env-file .env
--restart 重启策略 --restart unless-stopped
--network 连接网络 --network mynetwork
--rm 退出后自动删除容器 --rm（常用于一次性任务）
-it 交互式终端 -it（和 exec 配合）

4.4 COPY vs ADD

COPY vs ADD 怎么选？

COPY ADD
复制本地文件 ✅ ✅
自动解压 tar ❌ ✅
下载 URL ❌ ✅
行为可预测 ✅ 高 ⚠️ 低

原则：永远优先用 COPY，只在需要自动解压时才用 ADD。

4.5 CMD vs ENTRYPOINT

CMD ENTRYPOINT
用途 提供默认命令 定义容器入口
可被覆盖 ✅ docker run image cmd ⚠️ 需 --entrypoint
共存时 作为 ENTRYPOINT 的参数 接收 CMD 为默认参数

8. Docker 网络

Docker 默认创建三种网络：

网络类型 驱动 说明
bridge（默认） bridge 单机容器间通信，通过容器名互访
host host 容器直接使用宿主机网络栈
none null 完全隔离，无网络

9. Docker 数据卷

容器本身是无状态的——删除容器后，里面的数据就没了。数据卷（Volume）解决数据持久化问题。

9.1 三种存储方式

方式 命令 适用场景
命名卷（Volume） -v pgdata:/var/lib/postgresql/data 生产环境，由 Docker 管理
绑定挂载（Bind Mount） -v ./app:/app 开发环境，同步宿主机文件
tmpfs --tmpfs /tmp 临时数据，存内存中
